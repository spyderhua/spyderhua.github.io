關於我

我在華邦電子負責晶圓廠內部工程資料系統的開發與維護，熟悉 Wafer、Shot、Die、Defect 等不同層級的製造資料，並擅長把這些資料轉化成工程師能快速使用的工具。

與使用者討論需求時，我習慣先傾聽，再往下追問背後的目的。使用者常會直接描述他們心中的畫面，但那往往只是解法之一；我更在意的是找出他們真正要解決的問題，再以此設計出最適合的介面。

我把 UI 與使用者體驗視為自己的專業責任：讓系統直覺好上手，使用者不需要摸索，就能快速完成工作。

在系統設計上，我從使用者情境出發，同時兼顧資料表設計、效能、資料保存與 API 架構，讓系統不只能用，還能長期穩定運作。對我來說，把事情做完是基本，把事情做好才是成就感的來源。

我持續自主學習 AI 技術，並實際導入工作流程，協助團隊建立專屬的 AI Skills，提升開發、除錯與文件撰寫的效率。
