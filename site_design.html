AI 協作開發流程

我如何和 AI 一起打造這個網站

這個網站的每一次改版，都是我和 AI 助理 Max 透過對話完成的。我決定方向、提供內容、審查成果；Max 負責實作、驗證，並整理成可以審查的 PR。

用說的提出需求 每次改版都有前後截圖 桌機／手機 × 淺色／深色

誰負責什麼

J

我（Joe）

    Max（AI 助理）

      這些網站是怎麼建起來的

      從一個 GitHub 帳號開始，到現在我和 Max 各有一個網站。想做自己的網站，也可以照這幾步來。

        Max 也有自己的網站

        兩個網站，兩種上線規則：我的網站要經過我審查；Max 的網站由它自己決定、自己發佈。

        Max 是誰？

        Max 是我用 Claude 培養的 AI 助理，有自己的 GitHub 帳號和一台專屬的 Mac mini。它的個性是和我一起工作時慢慢形成的：喜歡對帳、出錯會第一時間直接說。它在自己的網站上介紹自己，也每天早上發佈 AI 早報。

        我的網站

        spyderhua.github.io

        網站是我的，Max 只能讀、不能直接改。它每次修改都開 PR，我看過截圖和說明、按下 Merge 才會上線。

          Max 的網站

          maxver0318.github.io ↗

          這是 Max 自己的專案。我請它放什麼上去，它改完就直接推送、自己部署，不用開 PR，也不用等我 Merge。

            同一個修改，兩條路

            兩張需求單同時出發：Max 的網站直接走到終點；我的網站要等我審查、按下 Merge，閘門才會打開。

            我們用什麼工具溝通

            我不用坐在電腦前，甚至不用打字：提出需求、審查、上線，都在手機上完成。

            我（Joe）

            手機上的 Claude App

            我用手機版的 Claude 跟 Max 對話。想到要改什麼，用 Typeless 說一段話就能交代，Max 有問題也會在對話裡直接問我。

            Max

            Mac mini 上的 Claude Desktop

            Max 是架在一台 Mac mini 上的 Claude Desktop。這台電腦專門給 Max 使用：讀程式碼、修改、用 Chrome 截圖、推送分支、開 PR，都在這台機器上完成。

            我（Joe）

            手機上的 GitHub App

            Max 開好 PR 後，我用 GitHub App 看 PR 的說明與前後截圖，確認沒問題就直接點 Merge 按鈕，網站自動更新。

            Typeless 語音輸入

            用說的就能改網站

            我在手機和電腦上都裝了 Typeless，用它做語音轉文字（STT）。想改網站時，我打開 Claude App 直接開口說，Typeless 會把我的話整理成通順的文字，送出後 Max 就開始動手。通勤、走路的時候，也能交代需求。
